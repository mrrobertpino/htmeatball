Meet HTMeatbalL.

  1. Add a block. Drag from the block box, or click to add it at the bottom.
  2. Make it yours. Type in the white fields. Your website changes immediately.
  3. Nest things. Drop into a container’s open space. A paragraph holds text, links, and emphasis; lists hold list items. Nest bold, italic, and underline blocks to combine them on the same text. Highlight words in a text block, then click Bold, Italic, or Underline in the block box. The text block splits around your selection. You can also drag one onto a text block to format all its text.
  4. Move without dragging. Use a block’s Move button, then click a placement bar. ↑ and ↓ reorder it.
  5. See the code. Switch HTML to Text and back. CSS also has blocks: choose a selector, then add style properties. CSS starts off. Choose the CSS tab to build styles with blocks or edit the stylesheet as text. Its switch lets you compare your styled page with plain HTML. JavaScript starts off. JavaScript uses text.
  6. Keep your work. Export HTML or CSS separately, and import an .html or .css file to continue editing. Importing replaces the matching editor's contents, so export your work first.
