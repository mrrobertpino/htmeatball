Meet HTMeatbalL.

  1. Add a block. Drag from the block box, or click to add it at the bottom.
  2. Make it yours. Type in the white fields. Your website changes immediately.
  3. Nest things. Drop into a container’s open space. A paragraph holds text, links, and emphasis; lists hold list items. Nest bold, italic, and underline blocks to combine them on the same text.
  4. Move without dragging. Use a block’s Move button, then click a placement bar. ↑ and ↓ reorder it.
  5. See the code. Switch HTML to Text and back. CSS also has blocks: choose a selector, then add style properties. CSS and JavaScript begin off; turn each on in its tab to see its effect. JavaScript uses text.
  6. Keep your work. Download your page before leaving or refreshing.
